MÄR Heaven: Knockin' on Heaven's Door - English translation v{version}
=====================================================================

Unofficial English fan translation of MÄR Heaven: Knockin' on Heaven's Door (Game Boy Advance, Konami, 2005).
This zip holds a patch only. It contains no game data: you need your own dump of the Japanese cartridge.
Do not share patched ROMs.

How to patch
------------
1. Check your dump matches the base ROM below (most patchers print the CRC32, or use any hash tool).
2. Apply {patch} with a BPS patcher: Rom Patcher JS (https://www.marcrobledo.com/RomPatcher.js/), Floating IPS
   (Flips) or beat.
3. The patched ROM should match the "Patched" hashes below.

Base ROM (No-Intro: MAER Heaven - Knockin' on Heaven's Door (Japan).gba)
  size   {base_size} bytes
  CRC32  {base_crc32}
  MD5    {base_md5}
  SHA-1  {base_sha1}

Patched
  CRC32  {out_crc32}
  SHA-1  {out_sha1}

Start a new game from a cold boot. Save files from the Japanese version work, but savestates from it do not.
Tested in MesenCE 2.2.1 (with the official GBA BIOS).

Known issues
------------
- A few graphics with text could only be checked in a preview, not in game: area name cards, the recipe and
  password input prompts, the link-cable messages (no second GBA to test with).
- Some staff names are romanised from kanji whose reading is not certain.
- Report problems at https://github.com/minhnhattonthat/maer-heaven-knockin-on-heaven-s-door-en/issues
  (a save file helps most).
